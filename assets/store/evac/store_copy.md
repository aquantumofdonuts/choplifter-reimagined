## Full Description (4,000 chars max)

```
THE CALL COMES IN. YOU'RE THE ONLY OPTION.

EVAC is a side-scrolling action game about one thing: getting everyone out alive. Pilot a rescue helicopter deep into hostile territory, locate stranded civilians, and extract them before the enemy can stop you.

Five environments. Escalating resistance. No second chances.

OPERATIONS
━━━━━━━━━━
Deploy across five distinct combat zones — scorched desert flats, dense jungle canopy, frozen arctic tundra, a volcanic tropical island, and an alien-controlled sector where the rules change entirely. Each zone has its own threats, its own music, and its own rhythm. Master all five.

HOW IT WORKS
━━━━━━━━━━━━
• Fly left or right across a wide scrolling battlespace
• Engage or avoid enemy tanks, jets, and alien craft
• Land near hostages, board them, and return to base
• Fuel is finite — prioritise your approach
• The enemy escalates. Each successful rescue brings faster threats.

MODES & VISUALS
━━━━━━━━━━━━━━━
EVAC ships with three renderer modes selectable from the menu:
• Retro — authentic classic pixel look, monochrome sprites
• Modern — sharp Endesga-32 pixel art, dynamic lighting
• Hi-Res — painterly, high-resolution assets (v2.0)

The soundtrack adapts in real time. Three layered music tracks per biome — calm, tension, action — crossfade based on the threat level around you.

DESIGNED FOR MOBILE
━━━━━━━━━━━━━━━━━━━
Floating virtual joystick, responsive tap-to-fire, and a clean heads-up display designed for phones. Bluetooth controller support built in. Plays in the browser too — same experience, no install required.

No ads. No purchases. EVAC is a complete game.
```
