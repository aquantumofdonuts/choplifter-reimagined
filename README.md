# Choplifter Clone

A modern clone of the classic 1982 Broderbund arcade game *Choplifter*, in which the player pilots a helicopter to rescue hostages from enemy territory.  Based on the reverse-engineered Apple II source code by Quinn Dunki (Blondihacks) and inspired by the original game design by Dan Gorlin.

## Overview

- **Genre:** Side-scrolling action / rescue
- **Inspiration:** [Choplifter (1982)](https://en.wikipedia.org/wiki/Choplifter) by Dan Gorlin / Broderbund

## Gameplay

- Fly a helicopter behind enemy lines
- Rescue hostages and return them to base
- Avoid/destroy enemy tanks, jets, and ground fire
- Limited fuel and ammunition add urgency
